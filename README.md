# Manna for the Skin

A responsive, static storefront concept for Manna for the Skin.

## Structure

- `dist/index.html` — page content and accessible structure
- `dist/styles.css` — responsive visual system
- `dist/script.js` — mobile navigation, shopping cart demo, and email validation
- `dist/assets/` — optimized site imagery

Product names, prices, contact details, and checkout behavior are clearly isolated for replacement when the final catalog and commerce provider are selected.
